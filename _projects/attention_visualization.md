## Features

- **Sentence-level attention heatmaps**: Visualize attention scores between words in different sentences
- **Multiple attention types**: Explore Cosine Similarity, Dot Product, and other attention mechanisms
- **Interactive matrix exploration**: Click on cells to see detailed attention scores
- **Automated insights & analysis**: Get instant analysis of attention patterns

This educational tool provides an intuitive way to understand how attention mechanisms work in transformer models and natural language processing tasks. It helps visualize how models learn to focus on relevant parts of input when processing sequences.
